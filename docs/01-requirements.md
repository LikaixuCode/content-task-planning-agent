# 需求与验收

运营人员输入主题、预算和截止时间，获得在约束内可保存的内容活动方案。方案包含拟执行任务、模拟费用、预计工期、规划工具的实际状态及结果。活动发布和真实业务系统不在范围内。

验收要求：

1. 素材可用、预算和时间充足时，生成并保存方案。
2. 缺少预算或截止时间时，明确指出缺失项，不调用模型或保存方案。
3. 某候选方案超预算或超期时，模型可以重新估算其他候选方案；所有候选方案不可行时报告缺口和未完成。
4. 工具失败必须记录失败；后续选择其他方案或停止时，保留已成功步骤。
5. 相同请求重复执行不产生新方案；同一请求 ID 的内容变化时报冲突。
6. 工具执行次数或 SDK 轮次达到上限而中断时，返回未完成并保留已有结果；显式续跑时复用成功结果。

成功指“方案已保存且规划运行完成”，不指活动已经实际执行。真实模型决策须由真实调用和工具 Trace 验证；离线 Mock 仅验证流程。
